UIManager.cs MODIFICAR Coordinador fino. Tiene referencias a HUDView, LoadoutView, MinimapView, LevelUpView, PauseView. Delega todas las llamadas.
HUDView.cs NUEVO Barra XP (Slider), badge de nivel (Text), timer (Text), corazones (lista de Images), chip de oro (Text). Expone métodos: SetXP, SetLevel, SetTime, SetHearts, SetGold.
LoadoutView.cs NUEVO 3 slots de arma con icono + pips de nivel (hasta 8). Fila de pasivos (slots dinámicos). Expone: SetWeaponSlot, SetPassiveSlot.
MinimapView.cs REEMPLAZA MinimapController RenderTexture de cámara ortográfica dedicada, blips de jugador/enemigos. Mismo API que MinimapController pero con estilo del diseño.
LevelUpView.cs NUEVO Overlay de 3 cards con icono, rareza, nombre, descripción. Botones Reroll (contador) y Skip (+50 oro). Se activa/desactiva via UIManager.
PauseView.cs NUEVO Panel de pausa con stats (tiempo, nivel, oro), botones Continuar/Ajustes/Abandonar.
GameManager.cs MODIFICAR Añadir currentGold como propiedad pública. El gold ya existe pero no se expone al HUD.
PlayerStats.cs MODIFICAR Exponer currentHealth y maxHealth públicamente para que HUDView calcule los corazones.
InventoryManager.cs MODIFICAR Añadir weaponLevel[] para los pips. Notificar a LoadoutView al equipar/subir nivel.
